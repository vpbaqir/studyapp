# StudyApp

A premium, minimalist Flutter study companion based on the supplied UI references.

## Included

- Home dashboard
- Subject cards with progress
- Working Pomodoro focus timer
- Study progress analytics
- Student profile
- Light and dark themes
- Responsive subject grid
- Reusable design components
- No external runtime dependencies

## Run

```bash
flutter pub get
flutter run
```
